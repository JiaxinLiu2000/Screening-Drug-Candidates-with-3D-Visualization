# EGFR self-docking benchmark (v2)

Generated by `src/17_docking_benchmark_v2.py`. No docking is run here.

## Protocol note - two different uses of docking

1. **Engine pose accuracy (self-docking; this set).** Each ligand is docked back into its *own* cognate receptor (`receptors/benchmark_v2/<PDB>_receptor.pdb`), inside a box built from its *own* crystallographic ligand (`pocket_center` / `pocket_box_*` in `<PDB>.json`, ligand bbox + 5 A per side), and the predicted pose is scored by heavy-atom RMSD against its *own* crystal pose (`<PDB>_ligand.sdf`). This is the Vina vs DiffDock comparison. Because receptor and ligand come from the same crystal, the receptor is already in the conformation that ligand selected, so RMSD measures the engine, not conformational tolerance. Results are reported overall and per alphaC state.
2. **Screening (1M17).** Novel molecules are docked into the single screening receptor 1M17 (active, erlotinib-bound; `receptors/` Phase 1 artefacts from `src/05_egfr_structure.py`). There is no crystal pose, so no RMSD; this use produces scores/rankings only. Neither the benchmark_v2 receptors nor their boxes are used for screening, and 1M17 is not used for pose-accuracy evaluation.

Phase 2's set (`receptors/benchmark/`, 17/20 inactive) remains on disk unchanged; docking its ligands into 1M17 would have conflated engine error with active-vs-inactive receptor mismatch, which this set avoids.

## Selection

- RCSB query: UniProt P00533, X-ray, `resolution_combined <= 2.8` (cached payload + IDs in `data/raw/rcsb_P00533_xray_le2.8.json`): **271** entries. RCSB exposes no conformational-state attribute, so every entry was screened and the salt bridge measured from coordinates on each one that passed the quality filters.
- Quality filters (identical to Phase 2): exactly one non-polymer ligand with 15-60 heavy atoms; ligand contacts the kept chain; no REMARK 465 residue in or sequence-adjacent to the 5 A pocket; CCD template maps onto the crystal copy; then one entry per ligand InChIKey.
- Filter relaxation: **no filter relaxed (same bounds as Phase 2)**
