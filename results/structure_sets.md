# Structural benchmark sets

Generated by `src/40_structure_sets.py`.

## 1. What this replaces

The Phase 2/4 docking set is 20 co-crystal structures of a single protein (P00533, EGFR), selected from 271 RCSB hits. Pose-accuracy numbers computed on it describe one binding site, so they cannot be read as a statement about docking methods in general. `results/PHASE2_DECISIONS.md` said so at the time; this is the fix, not a new discovery.

## 2. Replacements

| set | complexes | distinct PDB entries | distinct protein chain-sets | largest single-protein group |
|---|---|---|---|---|
| Phase 2 EGFR set (superseded) | 20 | 20 | 1 | 20 |
| PoseBusters benchmark | 428 | 428 | 428 | 1 |
| Astex Diverse | 85 | 85 | 85 | 1 |

The PoseBusters set multiplies the number of complexes by 21.4x, and no two of its complexes share an identical set of chain sequences.

**How to read the protein column.** Chains are compared by exact sequence, taken from the CA atoms because these files carry no SEQRES records. Exact matching splits different constructs or truncations of the same protein into separate groups, so the column is an upper bound on the number of distinct proteins rather than a count of them - on PDBbind the same procedure maps 5311 complexes onto 3186 sequences, so it does merge entries when they are truly identical. The comparison that does not depend on the threshold is the one that blocked the Phase 2 claim: that set was 20 structures returned by a single query for one UniProt accession (P00533), whereas these sets were assembled to span unrelated targets.

## 3. PDBbind refined set

5311 complexes, 5311 distinct PDB entries, 3186 distinct protein sequences, 4303 distinct canonical SMILES.

Affinity is reported as pKd/pKi (-log10 M), range 2.00 to 11.92, median 6.42. This matters beyond the docking work: every affinity number in this project so far comes from KIBA or DAVIS, and the KIBA target is a KIBA score rather than a binding constant. PDBbind is the first set here with a physical unit and the first opportunity to test the affinity model outside its training distribution.

The official PDBbind structure archive requires registration, so only the affinity table is mirrored; coordinates for any docked subset come from RCSB.
