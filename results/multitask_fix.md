# Multi-task interference: diagnosis and repairs

Generated by `src/39_multitask_fix.py`. Toxicity is the Tox21 scaffold split, affinity the KIBA random split - the same committed folds configurations A-F used.

## 1. What the Phase 3 result actually measured

Configuration A (GIN, toxicity only) reaches 0.7689 macro ROC-AUC; configuration C (same encoder shared with affinity) reaches 0.6820, a penalty of 0.0869. The same sharing costs ChemBERTa -0.0016, i.e. nothing.

That asymmetry is explained by the trainer rather than by the tasks. `tox21lib.train.train_model` iterates the two task loaders in sequence, taking a separate optimiser step per batch, so the two task gradients never coexist. Affinity runs last and, as the table below records, supplies far more batches per epoch, so the shared encoder ends every epoch updated almost entirely by affinity while toxicity is validated on it. A from-scratch GIN forgets under that treatment; ChemBERTa is pretrained and runs at a 50x lower encoder learning rate, so it does not.

Batches per epoch: 20 toxicity vs 367 affinity, a ratio of 18.35.
