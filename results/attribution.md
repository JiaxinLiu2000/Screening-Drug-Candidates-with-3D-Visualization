# Atom-level attribution for the toxicity model

Method: for every heavy atom, its feature row is replaced with the unknown-atom vector (all features zero) and inference is re-run; the attribution is the drop in predicted probability. One vector per molecule per endpoint, ordered to match the canonical-SMILES atom order. Model: configuration A (GIN from scratch, toxicity only), seed 0, evaluated on the scaffold-split test fold. Generated by `src/22_attribution.py`.

There is no ground truth for atom attribution, so this is validated qualitatively: does the signal concentrate on substructures that toxicologists already treat as alerts?

## Where it fails

- **Diffuse attribution**: 2 of 252 molecules have a normalised attribution entropy above 0.95, i.e. the signal is spread almost uniformly over every atom and carries no localised explanation.
- **Off-target attribution**: 74 molecules put the top-3 atoms outside the alert AND concentrate less than half the uniform share of attribution mass on it.
