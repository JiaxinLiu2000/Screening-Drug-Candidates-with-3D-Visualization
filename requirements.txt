# Python 3.11 (developed and verified on CPython 3.11.17, Windows x86_64).
#
# COMPLETE lock: every direct and transitive dependency is pinned, so it MUST be
# installed with --no-deps:
#
#     python -m venv .venv
#     .venv/Scripts/python -m pip install --no-deps -r requirements.txt
#
# Why --no-deps: PyTDC 0.4.1 declares a dependency on `rdkit-pypi`, which installs
# into the same `rdkit/` package directory as the modern `rdkit` wheel. Letting the
# resolver run installs both and whichever lands last silently overwrites the
# other, so `rdkit.__version__` becomes install-order dependent. Resolving nothing
# and pinning everything avoids that.
#
# Notes on specific pins:
#   - setuptools is held below 81 because PyTDC 0.4.1 imports `pkg_resources`,
#     removed in setuptools 81.
#   - the `dataclasses` backport PyTDC pulls in is deliberately absent: it is a
#     Python 3.6-only package that shadows the standard library on 3.11.
#   - torch is the CUDA 12.6 build (`+cu126`), which is NOT on PyPI. The
#     --extra-index-url line below makes `pip install --no-deps -r
#     requirements.txt` resolve it; CPU-only machines can swap that index for
#     https://download.pytorch.org/whl/cpu and drop the `+cu126` local version
#     from the torch pin. Nothing else in the lock changes.
#
# Regenerate with the freeze of a known-good environment (src/15_data_audit.py
# checks this file against the installed set in both directions).
