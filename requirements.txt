# Python 3.11 (developed and verified on CPython 3.11.17, Windows x86_64).
#
# This is a COMPLETE lock: every direct and transitive dependency is pinned, so
# it MUST be installed with --no-deps:
#
#     python -m venv .venv
#     .venv/Scripts/python -m pip install --no-deps -r requirements.txt
#
# Why --no-deps: PyTDC 0.4.1 declares a dependency on `rdkit-pypi`, which
# installs into the same `rdkit/` package directory as the modern `rdkit`
# wheel. Letting the resolver run installs both, and whichever lands last
# silently overwrites the other's files - the build is then not reproducible
# and `rdkit.__version__` depends on install order. Resolving nothing and
# pinning everything avoids that entirely.
#
# Two further pins worth knowing:
#   - setuptools is held below 81 because PyTDC 0.4.1 imports `pkg_resources`,
#     which setuptools 81 removed.
#   - the `dataclasses` backport that PyTDC pulls in is deliberately absent:
#     it is a Python 3.6-only package (`Requires-Python <3.7`) and shadows the
#     standard library on 3.11.
