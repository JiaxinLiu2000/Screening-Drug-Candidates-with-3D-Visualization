四、本轮发现并修掉的三个真实缺陷

这些不是进度条上的格子,但比格子重要——它们都会让已发布的数字变成错的。

缺陷症状修复
受体准备系统性失败
对接实验		 日志里约三分之一是 mk_prepare_receptor failed。 原因:PoseBusters 的受体保留了辅因子和修饰残基(例如 A:202: 'CO'), Meeko 没有对应模板。我们自己清洗过的 EGFR 受体不会碰到,所以此前一直没暴露。 加了一次 --delete_residues 回退(第一次尝试保持原样,以免改动已发表的 Phase 2 数字), 并按到晶体配体的距离设闸:删除的残基若有任何原子在 6 Å 以内,该结构直接排除而不是对接后计入。 实测 7P4J_5JK 需删 34 个残基,其中 A:903、A:911 就在结合位点内—— 只按「删除数量」放行会把它当成成功案例。
缺产物时返回裸 500
应用后端		 ApplicabilityError 与 ModelContractError 是 ServiceError 的 兄弟类而非子类,而端点只捕获后者。结果:新克隆的仓库访问 /api/targets 得到 500 Internal Server Error, 那句「请运行 src/38_export_models.py」被完全吞掉。 在 get_bundle() 一处统一转换。现在返回 503 + 可操作提示。
亲和力数字被呈现得有误导性
应用 + 幻灯片		 我一直在写「KIBA 范围 0.0–17.2」。但那 17 个单位的跨度由极少数极端值撑起, 74.7% 的真实值其实落在中位数 ±0.6 之内,四分位距只有 0.75。 这让「预测值全都差不多」看起来像模型坏了。散点图还自动贴合当批数据, 把 1.4 单位的差异拉满整个画幅。 实测 std(预测)/std(真实) = 0.8718,理论最优收缩比 ≈ Pearson r = 0.8487 ——模型几乎把标签方差用满了,没有退化。 改掉四处单位文案,散点图改为锚定真实分布并画出参照带。
